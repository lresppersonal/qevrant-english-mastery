## overview | overview | Overview and purpose
A **purpose** clause states an intention: *She moved to Vienna **to be** closer to her family.* A **result** clause states a consequence: *The lecture was **so** dense **that** most of us gave up.* Advanced learners need a range of both, because repeating *so* and *to* makes writing monotonous, and because some structures carry formal or negative meanings that others do not.

## theory | theory | How it works: aim versus consequence
Purpose looks **forward from the agent's mind**: the outcome may or may not happen. Result looks **backward from what actually happened** (or would happen). Compare:
> ex: He left early **so that** he **would** catch the train. || purpose: his aim
> ex: He left early, **so** he caught the train. || result: what happened
The modal verb is the clue: purpose clauses with *so that / in order that* usually contain **can, could, will, would, might**, because they describe a possible future seen from the agent's point of view. Result clauses usually do not.
!rule Negative purpose is awkward with *to*: *~~He whispered not to wake the baby~~* is possible but less clear than *so as not to wake* / *so that he wouldn't wake* / *in order not to wake*.

## form | form | Formation: the main patterns
#### Purpose
| Structure | Example | Notes |
| to + infinitive | *I came **to** help.* | most common; same subject |
| in order to / so as to | *We met early **in order to** prepare.* | more explicit; negative: *in order not to, so as not to* |
| so that + modal | *Speak up **so that** everyone **can** hear.* | different subjects possible |
| in order that + modal | *Records are kept **in order that** errors **may** be traced.* | formal |
| for + noun / -ing | *We stopped **for** lunch.* / *a tool **for** cutting* | *for* + -ing describes function, not a person's purpose |
| for fear (that) / in case | *She took notes **for fear that** she might forget.* | avoiding something |
| lest + (should) / subjunctive | *They spoke quietly **lest** they **(should) be** overheard.* | very formal, literary |
#### Result
| Structure | Example |
| so + adjective/adverb + that | *It was **so** loud **that** we left.* |
| such (a) + (adjective) + noun + that | *It was **such a** loud concert **that** we left.* |
| so much/many/few/little + noun + that | *There were **so many** errors **that** the paper was rejected.* |
| too + adj + (for sb) + to | *The text is **too** long **to** read in an hour.* |
| adj + enough + to | *She's experienced **enough to** lead the team.* |
| so / therefore / consequently / as a result | *Funding was cut; **consequently**, the project stopped.* |
| with the result that / so much so that | *Demand rose sharply, **so much so that** prices doubled.* |

## uses | uses | Main uses
#### Choosing a purpose structure
- Same subject, positive purpose → *to* (neutral) or *in order to* (emphatic, formal).
- Negative purpose → *so as not to / in order not to / so that ... not*.
- Different subjects → *so that* + modal: *I'll print it **so that** you **can** read it on the train.*
- Avoiding a risk → *in case* (precaution), *for fear that* (anxiety), *lest* (formal/literary).
#### Choosing a result structure
- Degree leading to a consequence → *so ... that / such ... that*.
- Excess or sufficiency → *too ... to / enough to*.
- Linking sentences → *therefore, consequently, as a result, hence, thus*.
!tip *Hence* and *thus* can introduce a noun phrase: *The data were incomplete, **hence** the delay.*

## examples | examples | Examples in context, explained
> ex: The scheme was simplified **so as not to** discourage small businesses. || negative purpose, same subject (the planners)
> ex: Interviews were anonymised **so that** participants **could** speak freely. || different subjects: researchers / participants
> ex: The evidence was **so** compelling **that** the jury reached a verdict within an hour. || result of a degree
> ex: It was **such** an unexpected result **that** the team repeated the experiment. || *such* + noun phrase
> ex: Take an umbrella **in case** it rains. || precaution: not *so that it rains*
> ex: The city grew rapidly, **so much so that** housing could not keep up. || emphatic result
> ex: The policy was unpopular and **thus** short-lived. || formal result linking two adjectives

## contrasts | contrasts | Comparison with related structures
| Pair | Difference |
| *so that* vs *so* | *so that* (purpose, + modal) vs *, so* (result): *I saved money **so that** I could travel* / *I saved money, **so** I travelled.* |
| *in case* vs *if* | *in case* = as a precaution, before: *Bring a coat in case it's cold.* *If* = only under that condition: *Wear a coat if it's cold.* |
| *for* + -ing vs *to* | function of a thing vs purpose of a person: *a knife **for** cutting bread* / *I used it **to** cut bread* (~~for cutting~~ is unnatural here). |
| *so* vs *such* | *so* + adjective/adverb; *such* + (a) noun phrase: *so expensive* / *such an expensive hotel* |
| *too* vs *enough* | too = more than acceptable; enough = sufficient: *too young to vote* / *old enough to vote* |

## register | register | Register and stylistic nuance
!register Neutral: *to, so that, so ... that*. Formal: *in order to, in order that, so as to, consequently, thus, hence*. Very formal or literary: *lest, for fear that, such that* (*The design is **such that** maintenance is minimal*).
In academic writing, *in order to* is often wordy: *In order to test the hypothesis, we ...* can usually be *To test the hypothesis, we ...*. Use *in order to* when the purpose needs emphasis or would otherwise be ambiguous.

## errors | errors | Common mistakes advanced learners make
> x: I came here for study English. || I came here to study English.
> x: She saved money for to buy a car. || She saved money to buy a car.
> x: It was so a difficult exam that many failed. || It was such a difficult exam that ... / The exam was so difficult that ...
> x: Take my number so that you call me. || Take my number so that you can call me.
> x: He is enough tall to reach it. || He is tall enough to reach it.
> x: The room was too much small. || The room was much too small. / The room was far too small.

## advanced | advanced | Advanced applications
#### Inverted result clauses
For emphasis: ***So** severe **was** the damage **that** the bridge had to be closed.* ***Such was** the demand **that** tickets sold out in minutes.* These inversions are formal and rhetorical.
#### Purpose with passive and perfect infinitives
*The rules were changed **to be seen to** act fairly.* *Measures must be taken **so as to have completed** the audit by June.* Use sparingly; clarity first.
#### Result without a conjunction: participle clauses
*Prices rose sharply, **causing** widespread protests.* The -ing clause presents a consequence of the whole previous clause. Make sure the implied subject is the whole situation, not a noun that cannot logically cause the result.

## summary | summary | Summary
- Purpose: *to, in order to, so as to, so that + modal, in order that, for fear that, lest*.
- Result: *so ... that, such ... that, too ... to, enough to, so much so that, consequently, thus, hence*.
- Negative purpose: *so as not to, in order not to, so that ... not*.
- *In case* = precaution; *so that* + modal = aim; *, so* = result.
- Formal writing: *in order that, thus, hence*; literary: *lest*.

### [error] @errors B2+
Correct the sentence: *I joined the course for improve my writing.*
= I joined the course to improve my writing. | I joined the course in order to improve my writing.
> Purpose of a person → *to* + infinitive.

### [gap] @uses B2+
Speak slowly so that the audience ___ (can) follow you.
= can
> *So that* + modal for purpose with a different subject.

### [transform] @form C1
Combine with *too*: *The data set is very large. We cannot analyse it manually.*
= The data set is too large to analyse manually. | The data set is too large for us to analyse manually.
> *too* + adjective + to-infinitive.

### [mc] @register C1
Which is the most formal way to express purpose?
+ Records are kept in order that errors may be traced.
- Records are kept so we can find errors.
- Records are kept to find errors.
- Records are kept for finding errors.
> *In order that* + *may* is formal.

### [transform] @advanced C1
Rewrite with inversion beginning *So*: *The demand was so high that the website crashed.*
= So high was the demand that the website crashed.
> *So* + adjective + inverted *be* + subject + *that*.

### [mc] @contrasts C1
Which sentence expresses result, not purpose?
+ The roads were icy, so the race was postponed.
- The race was postponed so that nobody would be injured.
- They postponed the race in order to protect the riders.
- They postponed the race so as not to risk injuries.
> *, so* introduces a consequence.

### [context] @advanced C2
Choose the best ending: *Funding was withdrawn halfway through the study, ___*
+ hence the incomplete results.
- hence the results were incomplete for.
- so that the results were incomplete.
- lest the results were incomplete.
> *Hence* + noun phrase gives a concise formal result.

### [gap] @register C2
The witnesses were kept apart ___ they should influence one another. (one word, formal)
= lest
> *Lest* + *should* expresses negative purpose formally.

### [rewrite] @uses C1
Rewrite with *so much so that*: *The project was popular. The council extended it for two years.*
= The project was popular, so much so that the council extended it for two years.
> *So much so that* emphasises the degree that led to the result.
